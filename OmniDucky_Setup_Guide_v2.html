macOS: Open the .dmg file and drag the Arduino IDE icon into your Applications folder. First launch may require right-clicking → Open to bypass Gatekeeper.

🦆 OMNIDUCKY SECTION 03 / ESP32-S3 CONFIGURATION
Step 2 of 5

Configure Arduino IDE for ESP32-S3

Add the ESP32 board package and set the critical USB-OTG settings. Getting these right is everything.

1
Add the ESP32 Board Manager URL
In Arduino IDE, go to File → Preferences (Windows/Linux) or Arduino IDE → Settings (Mac).
Find the field labeled "Additional boards manager URLs". Click the small icon to its right to open the URL list. Paste this URL and click OK:
Board Manager URL
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
2
Install the ESP32 Board Package
Go to Tools → Board → Boards Manager. In the search field, type "esp32". You will see a package by Espressif Systems — this is the correct one (not by Arduino). Click INSTALL. This downloads about 200 MB and may take 3–5 minutes. When done, the button changes to "INSTALLED".
3
Select the ESP32-S3 Board
Go to Tools → Board → ESP32 Arduino. Scroll down and select ESP32S3 Dev Module. The title bar of Arduino IDE should now display "ESP32S3 Dev Module".
4
Apply All Required Settings — CRITICAL
Under the Tools menu, set every option exactly as shown in the table below. Wrong USB mode is the #1 cause of HID failure.
Setting Required Value Notes
Board ESP32S3 Dev Module Must be S3 specifically
USB Mode ⚠ CRITICAL USB-OTG (TinyUSB) HID won't work otherwise
USB CDC On Boot ⚠ CRITICAL Disabled Must be Disabled for HID
CPU Frequency 240MHz (WiFi/BT) Needed for Wi-Fi + HID together
Flash Size 4MB (or 8MB) Match your board's actual flash
Partition Scheme Default 4MB with spiffs Leave as default
Upload Mode UART0 / Hardware CDC Default value is correct
Upload Speed 921600 Fastest reliable baud rate
🚨
The Two Settings That Break Everything
If USB HID doesn't work after flashing, it is almost certainly because USB Mode is not set to "USB-OTG (TinyUSB)" or USB CDC On Boot is not "Disabled". These two settings override everything else. Double-check them every time before uploading.
5
Select the Serial Port
Connect your ESP32-S3 to your computer via USB. Wait 3 seconds, then go to Tools → Port. A new port should appear — on Windows it looks like COM3 or COM5, on Mac it's /dev/cu.usbserial-XXXX, on Linux it's /dev/ttyUSB0. Select it. If nothing appears, your USB driver is not installed — see Section 02, Step 5.

🦆 OMNIDUCKY SECTION 07 / TROUBLESHOOTING
Common Issues & Fixes

Troubleshooting Guide

Every problem has been encountered and solved. Find your error below.

🔌 No COM port appears in Arduino IDE after plugging in the board
Cause USB driver not installed, or the cable is a charge-only cable with no data lines.
Fix 1. Try a different USB cable — many cheap cables are power-only.
2. Install the CP210x driver (Silabs) or CH340 driver depending on your board's USB chip.
3. On Windows, check Device Manager for any yellow ⚠ icon under "Universal Serial Bus controllers".
⌨️ Board is flashed but target PC doesn't detect a keyboard
Cause USB Mode is set to "Hardware CDC" instead of "USB-OTG (TinyUSB)". This is the #1 error — it blocks all HID functionality.
Fix In Arduino IDE, go to Tools → USB Mode → USB-OTG (TinyUSB). Also set Tools → USB CDC On Boot → Disabled. Then re-upload the sketch. Never skip these two settings.
⏱️ Upload hangs at "Connecting....." and never starts
Cause Board is not entering bootloader/download mode automatically.
Fix While the IDE shows "Connecting.....", hold the BOOT button on the board → briefly tap RESET → release BOOT. Upload will begin. Some boards need this on every flash; others don't need it at all.
📶 "OmniDucky-C2" Wi-Fi network doesn't appear after flashing
Cause Board booted into wrong mode, or upload was incomplete.
Fix Open Serial Monitor (Tools → Serial Monitor) at 115200 baud. Press RESET on the board. You should see boot messages confirming Wi-Fi AP startup. If you see garbage text, your baud rate is wrong. Try re-flashing if no messages appear.
🛑 Compile error: "USB.h: No such file or directory"
Cause Wrong ESP32 board package version installed, or wrong board selected in Tools.
Fix In Boards Manager, verify the Espressif Systems esp32 package is version ≥ 2.0.5. Update it if needed. Confirm the board is set to "ESP32S3 Dev Module" — not standard ESP32 or ESP32-S2.
🎯 Dashboard loads but FIRE button does nothing on target PC
Cause ESP32 is plugged into a charger or hub with no data to target, or DuckyScript has a syntax error.
Fix Plug the ESP32 directly into the target PC's USB port (not a charger or USB hub). Check the status panel in the dashboard — it shows error messages from the interpreter. Ensure all DuckyScript commands are UPPERCASE.
